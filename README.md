# Золотая Лоза

Адрес сайта на GitHub Pages: https://pda2441.github.io/p1sun/ . Публикация настроена из main /; файл .nojekyll отключает обработку Jekyll. Ссылку можно отправлять в Telegram. Форма остаётся демонстрационной.

Портфолио-концепция ресторана грузинской кухни на русском языке. HTML5, CSS, JavaScript ES modules, локальные изображения и шрифты. Приложению не нужны сборка, backend, база данных или npm-зависимости.

## Запуск

Нужен **Node.js 24.22.1 LTS** — проверенная версия, закреплённая в `.node-version`. Восстановить можно с [официальной страницы Node.js](https://nodejs.org/en/download). Сервер использует только встроенные модули Node.

После клонирования `pda2441/p1sun` откройте корень репозитория (папку с `index.html`). При доступном Node:

```powershell
node scripts/server.mjs
```

Открыть **http://127.0.0.1:4173/**. Остановка — `Ctrl+C` в терминале сервера. Другой порт: `$env:PORT=4174` перед запуском.

Для текущего сохранённого workspace, из его корня, без настройки PATH:

```powershell
& .\tools\node\node.exe .\sites\ww-kima\scripts\server.mjs
```

Альтернатива с Node в PATH — `npm start`. `npm install` для запуска не требуется. Открытие `index.html` двойным щелчком не поддерживается: ES-модулям нужен HTTP-сервер.

Из CMD в текущей восстановленной среде:

```cmd
cd /d "C:\Users\Admin\Desktop\my-projects"
tools\node\node.exe sites\ww-kima\scripts\server.mjs
```

После переноса замените путь в `cd` на фактическую папку workspace (например, профиль `kirusha`). Открывайте `http://127.0.0.1:4173/`, а не файл HTML. Прямые адреса разделов: `/#home`, `/#menu`, `/#atmosphere`, `/#booking`. Если видна только главная, сначала проверьте, что адрес начинается с `http://`, затем ошибки загрузки `js/app.js` и `js/dishes.js` в DevTools.

Регрессия навигации: `node scripts/navigation-qa.mjs` при работающем QA-браузере, описанном в QA-отчёте. Браузерные сценарии запускайте последовательно: они используют один экземпляр Edge и его активную вкладку.

## Проверки

Из корня сайта:

```powershell
node --check js/app.js
node --check js/dishes.js
node scripts/verify.mjs
```

Альтернатива — `npm run check`. Результаты реальных браузерных сценариев и ограничения — [docs/qa-report.md](docs/qa-report.md). Скриншоты и машинный отчёт — `output/playwright/`; название каталога сохранено по правилам скилла, фактический браузерный инструмент указан в отчёте.

## Возможности

- Четыре адаптивных раздела, активная навигация, hash-адреса и Back/Forward.
- Двенадцать блюд, шесть категорий, диалоги с составами, аллергенами, весом и ценой.
- Галерея атмосферы с увеличением фотографий.
- Локальная проверка формы: имя, телефон, дата, время, гости и пожелания.
- Анимации вступления, переходов, фильтров и диалогов, появление секций и деликатный параллакс; reduced motion.
- Клавиатура, видимый фокус, Escape, ограничение фокуса диалогом и возврат фокуса.

После заполнения формы: **«Демонстрационная заявка. В ресторан не отправлена»**. Никакого запроса, брони, сохранения персональных данных или внешнего сообщения не происходит. Цены, рецепты и фотографии концептуальные.

## Структура и ресурсы

`index.html` — разметка; `styles/main.css` — оформление; `js/dishes.js` — единственный источник блюд; `js/app.js` — взаимодействия; `assets/` — локальные фотографии, SVG и шрифты; `scripts/` — сервер и проверки. Источники и лицензии — [docs/asset-sources.md](docs/asset-sources.md), референсы движения — [docs/design-references.md](docs/design-references.md).

Рабочие правила — `AGENTS.md` и `docs/working-rules.md`. Восемь выбранных скиллов сохранены целиком с исходными лицензиями и хешами: семь из workspace и снимок встроенного imagegen. Роли — в `agents/` и `.codex/agents/`. `scripts/import-workspace-kit.mjs` использован однократно для проверенного переноса инструкций; требует родительский workspace, **не нужен для работы сайта и не должен исполняться поверх имеющихся пакетов**.

В [docs/recovery.md](docs/recovery.md) описано восстановление. Исходники подготовлены для репозитория `pda2441/p1sun` по поручению пользователя; хостинг и deploy не настроены. Для публикации сайта отдельно задать реальный домен в абсолютном `og:image` и `og:url`; адрес и контакты добавлять только после их получения. Каталог `output/` с локальными результатами QA и профилями браузера не входит в репозиторий; результаты проверок описаны в QA-отчёте.
