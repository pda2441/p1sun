# Самостоятельный сайт

Работай из корня этого репозитория. Общие правила полностью сохранены в `docs/working-rules.md`: прочитай их перед работой вместе с `docs/project-context.md` и `docs/progress.md`. Ссылки этих правил на рабочую my-projects описывают родительский комплект; в этом репозитории используй собственные пути, README, `docs/recovery.md` и `scripts/Test-SiteKit.ps1`.

Объясняй по-русски. Сначала изучай файлы; не отменяй чужие изменения. Выбирай стек по брифу; статическому сайту backend не обязателен. Реализуй и проверяй заявленные функции. Демо и моки обозначай; успешную отправку/оплату не имитируй. Секреты не сохраняй в коде и документах. Проверяй данные и права на сервере, доступность и ошибки.

Выбранные скиллы — `.agents/skills`, их происхождение — `docs/skills-lock.json`, авторские роли — `agents`, конфигурации Codex — `.codex/agents`. Загружай только подходящие скиллы. Наличие конфигурации не подтверждает запуск помощника; маленькие задачи делай одним агентом, при разделении назначай владельцев файлов.

Фиксируй фактически выполненные проверки и обновляй прогресс. Публикация, создание удалённого репозитория, push, PR, merge и deploy требуют явной задачи. Реальные платежи и сообщения подключай отдельно. Продолжай порученную локальную работу без постоянных подтверждений.
