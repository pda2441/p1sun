# Контекст «Золотая Лоза»

Текущее позиционирование по поручению пользователя: ресторан грузинской кухни «Золотая Лоза». Обозначение обновлено в интерфейсе, метаданных, alt-текстах и заголовке главного раздела.

27 октября 2026 пользователь переименовал кафе из WW KiMa в «Золотая Лоза». Название обновлено в интерфейсе и метаданных; техническая папка `sites/ww-kima` сохранена для совместимости команд запуска.

Дата создания: 2026-10-25. Самостоятельный проект в `sites/ww-kima`. Общие правила скопированы в `docs/working-rules.md`, роли — в `agents`, выбранные скиллы — в `.agents/skills` с происхождением и контрольными суммами.

Подтверждено: пользователь предоставил полный бриф и макет. Нужен законченный локальный сайт для портфолио на HTML/CSS/JavaScript, без реальных бронирований, публикации и внешних отправок. Все данные кафе являются концепцией.

Решение: семантический HTML, один CSS, ES-модули JavaScript. Нативные dialog, History/hash, Web Animations API, IntersectionObserver. Node.js нужен только для статического локального сервера и проверок. Производственных npm-зависимостей нет. API, авторизация и БД не применимы. React/PostgreSQL-правила к этому проекту не применяются.

Контракт данных: `js/dishes.js` экспортирует единственный массив 12 блюд. Карточки, избранные и диалоги используют этот массив. Категории: all/starter/hot/oven/dessert/drink. Разделы: #home/#menu/#atmosphere/#booking. Имена файлов изображений совпадают с id блюд.

Форма проверяет имя, телефон, дату в диапазоне сегодня…90 дней, время из списка 12:00…21:00 с шагом 30 минут, 1–8 гостей и комментарий до 500 символов. Результат существует только в DOM до изменения формы/перезагрузки; это не отправка и не сохранение.

Фактическая среда: Windows, переносимый Node.js 24.22.1. Системный PATH, политики выполнения и разрешения не изменяются. New-Site.ps1 отклонён политикой PowerShell; документационный шаблон перенесён вручную, без исполнения текста ps1.

Продолжение: README — запуск; docs/qa-report.md — реально выполненные проверки; docs/progress.md — текущее состояние и оставшаяся работа. Изменения общего workspace и папки coffe не требуются.
