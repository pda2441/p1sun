### Установленная причина и воспроизведение

1. Открыть index.html через file://, нажать «Меню»: hash меняется, но menu.hidden остаётся true, карточек 0. ES-модуль не выполняется из файлового origin. Это подтверждённое условие исходного симптома, а не доказательство способа запуска пользователя.
2. По HTTP открыть #home, отключить Element.prototype.animate через DevTools, нажать «Меню»: до исправления TypeError `element.animate is not a function` в animate → route, выбранный раздел остаётся скрытым. Смена hidden происходила только после запуска/окончания эффекта. `navigation-before.json` содержит ожидаемый FAIL и ошибку.
3. В обычном Edge исходные HTTP-ссылки работали. Ссылки соответствуют ID, модуль и ресурсы загружаются. Постоянного CSS-перекрытия, ошибочного pointer-events или конфликта display/visibility не обнаружено. Проверка кликами и скриншотами подтверждает доступность элементов.

## Визуальная доводка

Выполнен цикл «реализация → работающий браузер → просмотр PNG → исправления → повторная проверка».
