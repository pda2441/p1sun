# Границы интеграции

Прикладные API, backend, база данных и авторизация не применяются. Локальный Node-сервер отдаёт статические файлы только на 127.0.0.1. GET/HEAD поддерживаются, остальные методы получают 405. Неизвестный путь получает 404. Сервер не принимает бронирования.

Форма обрабатывается в браузере. Клиентская валидация улучшает демонстрационный сценарий, но не является серверной защитой. Ни fetch, ни XMLHttpRequest, ни отправка формы на внешний URL не используются; поля не пишутся в localStorage/sessionStorage, логи или файл.

После валидного заполнения показано: «Демонстрационная заявка. В ресторан не отправлена». Реальный сервис потребует отдельной задачи: endpoint, серверная проверка, обработка персональных данных, права, защита повторов, политика хранения, ошибки и явное подтверждение рестораном.
