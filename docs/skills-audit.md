# Скиллы этого проекта

## Фактическое применение — 2026-10-25

Сохранены восемь полных пакетов: frontend-design, web-design-guidelines, playwright, visual-quality-review, fullstack-validation, api-and-integration, environment-recovery и imagegen. Первые семь перенесены с проверкой исходных SHA-256 из workspace-manifest.json; imagegen — неизменённый снимок системного пакета Codex на дату создания, upstream commit неизвестен и не выдумывается. Лицензии и справочные файлы сохранены. Точные контрольные суммы — в локальном site-kit-manifest.json.

frontend-design применён к направлению макета и композиции. Для web-design-guidelines свежие правила https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md получены веб-инструментом 2026-10-25, проверены разметка, стили и взаимодействия. visual-quality-review использован с реальными скриншотами desktop/mobile и повторными исправлениями; сценарии — по fullstack-validation. imagegen использован через встроенный инструмент, промпты и результаты — в docs/image-prompts.md и docs/asset-sources.md.

playwright прочитан, проверены portable Node/npm, предпринята установка CLI, но npm registry вернул ETIMEDOUT. Поэтому выполнение именно Playwright CLI не подтверждается; вместо него реальные сценарии выполнены Edge/CDP штатным Node WebSocket. Код стороннего скилла не менялся. api-and-integration изучен для границ формы; прикладной API/БД не нужен. environment-recovery применён к диагностике запуска и инструкции переноса; ExecutionPolicy и системные разрешения не менялись.

Просмотрен каталог всех 14 workspace-скиллов с описаниями и условиями. React/Next, PostgreSQL, миграции, GitHub CI/review и security-скиллы не применялись: задача не соответствует их условиям. Sites изучен для выбора локального workflow; облачные вызовы, регистрация и публикация пропущены согласно прямому запрету пользователя.

Точный выбранный набор, происхождение, commit/версия и SHA-256 перечислены в `docs/skills-lock.json` и `docs/site-kit-manifest.json`. Пакеты скопированы целиком в `.agents/skills`, без обязательных внешних ссылок. Не менять upstream молча; до обновления сравнить локальные изменения и хеши. Отличающиеся копии не перезаписывать автоматически.

`docs/workspace-origin-audit.md` — исторический аудит исходного общего набора на 2026-10-23. Он описывает первоначальную подготовку, а не текущий статус всех пакетов в этом отдельном проекте. Установлены только пакеты из локального lock. При переносе заново подтвердить обнаружение клиентом, зависимости и реальное выполнение раздельно.

Особенности выбранных пакетов по необходимости:

- frontend-design задаёт направление, web-design-guidelines требует свежую загрузку правил с указанного им официального URL. При отсутствии WebFetch использовать доступный разрешённый fetch-инструмент, фиксировать источник/дату; без свежих правил полное выполнение не подтверждено.
- Playwright upstream использует Bash/npx и глобальный путь. Для локальной копии задавать в Bash `PWCLI="$PWD/.agents/skills/playwright/scripts/playwright_cli.sh"`; не менять CODEX_HOME ради обёртки. Проверить Node/npm/npx и браузерный инструмент до запуска.
- vercel-react-best-practices относится к React/Next.js; supabase-postgres-best-practices — к PostgreSQL. Наличие скилла не требует выбора этого стека.
- GitHub-скиллам нужны Git/gh, авторизация и конкретная задача. Не обходить запреты сети/эскалации. Внешние записи — только по явному поручению.
- Авторские скиллы созданы для рабочего процесса, а не выпущены поставщиками. Визуальная оценка требует реальных скриншотов и поддержки изображений.

Проверку файлов не считать приёмкой сайта. Команды, фактические результаты и ограничения обновлять в прогрессе и QA-отчёте проекта.
