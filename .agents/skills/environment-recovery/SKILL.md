# Восстановление среды

Авторский локальный скилл. Применять после сброса, переноса архива или сбоя запуска, а не перед каждой правкой.

1. Определить реальную ОС и папку. Читать setup-windows, контекст и прогресс. В отдельном clone использовать README и `docs/recovery.md` сайта: родительская my-projects может отсутствовать.
2. Для комплекта запустить `scripts/Test-Workspace.ps1`, для самостоятельного сайта — `scripts/Test-SiteKit.ps1`. Записать точные ошибки; не обходить sandbox и не менять разрешения/execution policy.
3. Сверить версии с README/lock-файлами. Различить отсутствующий executable, проблему PATH, зависимости, переменные и недоступный сервис. Не печатать секреты.
4. В рамках поручения восстановить нужное ПО и зависимости по lock-файлам. Не менять стек ради маскировки ошибки. Входы в аккаунты восстановить отдельно, ключи передать из защищённого хранилища.
5. Восстановить данные по инструкции сайта. Запустить его и проверить основной сценарий. Перечислить непроверенные внешние подключения. Не расходовать DeepSeek API ради проверки файлов.
6. Обновить прогресс: команды, результаты, версии, блокировки и следующий шаг. Перед сбросом сохранить полный ZIP my-projects вне сбрасываемого диска и проверить скрытые инструкции и восстановление.

Результат: подтверждённый запуск и основной сценарий либо воспроизводимая диагностика блокировки. Сохранённая папка не сохраняет установленное ПО, входы и процессы.
